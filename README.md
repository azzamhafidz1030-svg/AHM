# Portfolio — Azzam Hafidz Murobbi

Website portfolio pribadi berisi proyek-proyek coding, artikel sejarah & militer, game edukasi, dan tools.

## Cara Deploy ke Vercel + GitHub

1. Buat repository baru di GitHub (contoh: `portfolio-azzam`)
2. Upload **semua file** di folder ini ke root repository (jangan masukkan ke subfolder)
3. Buka [vercel.com](https://vercel.com) → Login dengan GitHub
4. Klik **Add New Project** → pilih repository tadi → Deploy

Link akan otomatis jadi: `https://portfolio-azzam.vercel.app`

## Struktur File

```
├── index.html                  ← Halaman utama
├── artikel.html                ← Artikel Militer & Sejarah
├── geography-quiz.html         ← Game tebak negara
├── kamus-turki.html            ← Kamus Turki-Indonesia
├── kuis-sejarah-1814-1945.html ← Kuis sejarah 120 soal
├── music-player.html           ← Music player dengan playlist
├── ahmtube.html                ← Video player (A.H.Mtube)
├── *.jpg                       ← Semua gambar
├── correct.mp3 / fahh.mp3      ← Sound effect kuis
└── README.md
```

## Catatan

- Semua path sudah diperbaiki (nama file tanpa spasi).
- Jangan ubah nama file gambar kecuali kamu juga ubah di HTML-nya.
