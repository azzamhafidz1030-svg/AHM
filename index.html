Sekilas tentang saya

Saya seorang siswa SMPIT Assyifa Boarding School. Di sekolah tersebut saya mengikuti ekstrakulikuler coding. Lewat website ini saya ingin membagikan pengetahuan dan karya saya serta melatih skill dalam coding website.

Saat tidak sedang coding, saya suka menggambar. Saya juga sedang menekuni belajar bahasa seperti Inggris, Arab, Turki, Rusia, Jerman, dan Jepang. Saya punya pengetahuan yang cukup luas dalam sejarah dan militer — itulah kenapa saya ingin membagikan pengetahuan saya seputar itu, semoga bermanfaat!
